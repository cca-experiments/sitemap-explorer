# Sitemap Explorer

An interactive tree of every page in the cancer.org.au XML sitemap, coloured by when each page was last updated.

- Live tool: https://cca-experiments.github.io/sitemap-explorer/
- Data: `data/sitemap.json`, refreshed every day by the "Update sitemap data" GitHub Action. To refresh now, open the Actions tab, choose "Update sitemap data" and click "Run workflow".
- Page titles, TAS/NT tags and the "In IA sheet" comparison come from the IA Google Sheet (link set at the top of `index.html`).
- Companion tool built from the IA spreadsheet: https://cca-experiments.github.io/ia-explorer/
